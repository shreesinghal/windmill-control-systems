# windmill-control-system  
## Directions 
In the Terminal or Mac equivalent, navigate to the location you want to store the Arduino code using cd {location on your computer}.  
Clone this repo onto your computer by typing "git clone https://github.com/reNU-Northeastern/windmill-control-system.git"  
In the File Explorer or Mac equivalent, navigate into the StepperMotorClass folder.  
Double click on StepperMotorClass.ino and open with the Arduino IDE. This should open all the Arduino files in the folder on separate tabs.  
  
*NOTE*: The code is read by the computer as a single script from the first tab to the last. Additionally, the tabs are always in alphabetical order after StepperMotorClass, hence the numbers in the file names.
