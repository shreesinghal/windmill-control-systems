# windmill-control-system

First iteration of windmill control system!!

Planning Doc: https://docs.google.com/document/d/1FtEYHDXMwyU5szHu0cpi73aLN-QFNFxVn527U2V7oYQ/edit?usp=sharing

To open and use the Arduino code, clone repo and navigate into the StepperMotorClass directory. Then, double click on StepperMotorClass.ino and open with the Arduino IDE. This should open all the arduino files in the folder on separate tabs.  
*NOTE*: The code is read by the computer as a single script from the first tab to the last. Additionally, the tabs are always in alphabetical order after StepperMotorClass, hence the numbers in the file names.
